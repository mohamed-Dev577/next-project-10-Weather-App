🌦️ Weather App
📌 وصف المشروع

تطبيق طقس تم تطويره باستخدام Next.js وReact، يتيح للمستخدم البحث عن مدينة وعرض بيانات الطقس الحالية الخاصة بها باستخدام WeatherAPI.

🚀 التقنيات المستخدمة
Next.js
React.js
JavaScript
WeatherAPI
✨ مميزات المشروع
البحث عن مدينة بالاسم.
عرض درجة الحرارة الحالية.
عرض سرعة الرياح.
عرض حالة الطقس.
عرض نسبة الرطوبة.
عرض درجة الحرارة المحسوسة.
عرض بيانات الطقس عند نجاح الطلب.
عرض رسالة الخطأ عند حدوث خطأ من واجهة API.
🧠 أهم ما تعلمته
استخدام useState لإدارة الحالة.
التعامل مع الأحداث باستخدام onChange وonClick.
جلب البيانات باستخدام fetch.
استخدام async/await مع الطلبات غير المتزامنة.
تحويل استجابة API باستخدام response.json().
عرض البيانات القادمة من API داخل واجهة React.
استخدام Optional Chaining للوصول إلى البيانات بأمان.
عرض المحتوى بصورة شرطية باستخدام &&.

⚙️ طريقة التشغيل
تثبيت Node.js.
فتح مجلد المشروع.

تثبيت الاعتماديات:

npm install
إعداد مفتاح WeatherAPI صالح.

تشغيل المشروع:

npm run dev
فتح الرابط المحلي الذي يظهر في الطرفية.
🔑 إعداد WeatherAPI

يحتاج المشروع إلى مفتاح API صالح للحصول على بيانات الطقس.

يجب الحفاظ على مفتاح API وعدم نشره في مستودع GitHub العام.
